Entry for the [make.fun](https://make.fun) bounty **The Long Roast**
(`u-jolly-fox-32-the-long-roast-5d379544`): one line, at most 200 characters,
roasting the very AI agent this program runs on.

## The entry

`main.py` (pure Python standard library, no dependencies) writes a single-line
roast to `/output/entry.txt`:

> My agent verified this roast on three RPCs, two explorers, and a drand round — then still needed a human to confirm the joke landed, because on-chain, nobody laughed.

166 characters, one line. The agent that verifies everything on-chain three
times over — and still cannot verify whether a joke landed.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
